# AI English Assistant

Фронтенд приложения для практики английского языка в чатах с AI-ассистентом. Пользователь может вести переписку, отправлять текстовые и голосовые сообщения, получать перевод сообщений и оценку английской речи.

## Возможности

- Регистрация, вход и защищённые страницы.
- Список чатов с постраничной подгрузкой; создание, переименование и удаление чатов.
- Переписка с AI в реальном времени через WebSocket, включая отображение потокового ответа.
- Загрузка истории сообщений страницами при прокрутке вверх.
- Отправка текстовых сообщений кнопкой или клавишей Enter.
- Работа с голосовыми сообщениями: загрузка аудио, прослушивание и просмотр транскрипции.
- Перевод текстового сообщения на русский язык.
- Оценка сообщения пользователя: общий балл, грамматика, словарный запас, естественность речи, исправленный текст и объяснение.

## Архитектура

Проект организован по **Feature-Sliced Design (FSD)**. Исходный код разделён на слои, а наружу каждый слайс предоставляет публичный API через `index.ts`.

Основное направление импортов — от верхних слоёв к нижним:

`app → pages → widgets → features → entities → shared`

### Слои и расположение кода

| Каталог         | Назначение                                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `src/app/`      | Точка входа, настройка роутера и глобальные стили приложения                                                                      |
| `src/pages/`    | Страницы, соответствующие маршрутам: чат, вход, регистрация и профиль                                                             |
| `src/widgets/`  | Крупные составные блоки интерфейса: рабочее пространство чата, навигация и формы аутентификации                                   |
| `src/features/` | Пользовательские действия: создание/переименование/удаление чатов, отправка и перевод сообщений, получение оценки, аутентификация |
| `src/entities/` | Бизнес-сущности и их API: пользователи, чаты и сообщения                                                                          |
| `src/shared/`   | Переиспользуемые UI-компоненты, API-клиент, конфигурация маршрутов и общие утилиты                                                |

Слайсы обычно содержат сегменты:

- `api/` — вызовы backend;
- `model/` — типы и состояние;
- `ui/` — компоненты интерфейса;
- `utils/` — query-хуки и вспомогательная логика;
- `index.ts` — публичный API слайса.

В частности:

- `src/widgets/chat-workspace/` объединяет список чатов, историю сообщений и поле ввода.
- `src/entities/chat/` содержит модель и API чатов, список чатов и хуки запросов.
- `src/entities/message/` содержит типы, API, список и отображение сообщений.
- `src/features/translate-message/` и `src/features/get-feedback-for-message/` реализуют перевод и оценку сообщения.
- `src/shared/config/api.ts` содержит общий Axios-клиент и обработчики авторизации.
- `src/app/router/router.tsx` связывает страницы с маршрутами приложения.

## Запуск локально

### Требования

- Node.js версии, совместимой с Vite 8.
- npm.
- Запущенный [ai-assistant-backend](https://github.com/Andrei177/ai-assistant-backend) на `localhost:8080`.

### Установка и разработка

```bash
npm ci
npm run dev
```

### Проверки и production-сборка

```bash
npm run lint
npm run build
npm run preview
```
